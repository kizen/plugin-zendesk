- Create Ticket: open a new ticket with a title, description, and optional requester, priority, type, status, tags, assignee, group, external ID, and custom fields.
- Update Ticket: change status, priority, type, assignee, group, tags, or custom fields on an existing ticket. Protected against concurrent-edit collisions.
- Add Ticket Comment: post a public reply or an internal note on an existing ticket, optionally changing status at the same time.
- Get Ticket: fetch a ticket's current state, including the requester's email.
- Get Ticket Comments: pull a ticket's full conversation thread as one formatted transcript, plus the most recent comment on its own.
- Search Tickets: find tickets by requester, status, priority, type, tags, organization, external ID, or date — or a raw Zendesk search query for full control.
- Find or Create User: look up a Zendesk end user by Zendesk User ID, External ID, email, or name, optionally creating one if no match exists.
- OAuth 2.0 business-level connection: each business connects its own Zendesk account via its own OAuth client.
